# 大模型面试资料（2026 进阶版）

一套面向大模型相关岗位的系统化面试资料，覆盖**算法（训练/微调/对齐/推理）**、**应用开发（RAG/Agent/上下文工程）**、**产品与解决方案**三条路线。

与常见“八股合集”的区别：

- **题库驱动**：整理了 2025–2026 公开面经中的高频问法，按主题归类并给出原创答案要点。
- **项目导向**：单独用一章拆解项目深挖，覆盖训练、SFT、RL、推理、RAG、Agent、多模态、评测八类项目。
- **进阶深度**：PPO/DPO/GRPO 推导、显存与容量计算、上下文工程、Harness/HITL/ACL 等 2026 新考点。
- **可练习**：含手撕代码题、系统设计题、90 秒答题框架和数字口径清单。
- **规模**：29 篇正文、约 500 个题目/追问、200 条术语，另附公式速查与公开来源链接。

> 当前版本：2026-10。大模型领域迭代很快，具体模型规格、价格、榜单请以官方文档和原始论文为准。资料中的数字均标注“量级/估算”，用于建立直觉，不作为工程验收依据。

## 2026 面试在考什么

根据公开面经与题库的整理，近两年有三个明显变化：

1. **从“背定义”到“推公式 + 算账”**：RoPE 要能推相对位置，SwiGLU 要能算 $8d/3$，KV Cache 要能现场估显存，分布式要能给 70B 配并行。
2. **从“技术点”到“项目数字”**：几乎每道概念题后面都会接“你们具体怎么做的、效果怎么量化、失败 case 怎么定位”。
3. **应用岗新增四大重灾区**：上下文工程（压缩/污染/预算）、Skill 与 Harness、HITL 与 ACL、Token 治理与可观测性；RAG 从“一次检索”升级到 Agentic RAG。

对应地，本资料把“基础文档”和“进阶专题/题库”分开：先用基础文档建立框架，再用题库和项目章节做面试表达训练。

## 适合谁

- 准备大模型算法岗（预训练、后训练、推理优化、多模态）的候选人。
- 准备大模型应用岗（RAG、Agent、应用架构）的工程师。
- 准备 AI 产品/解决方案岗的产品经理、架构师。
- 已有基础，但一被追问“为什么、怎么算、项目里怎么落地”就答不深的人。
- 想系统梳理知识体系、而不是收藏一堆面经的学习者。

## 题库怎么用

资料里有四类题库，定位不同，不要重复刷：

| 文档 | 定位 | 用法 |
| --- | --- | --- |
| `06-01 算法岗高频问答` | 系统覆盖 85 个算法考点 | 第一遍查漏，第二遍口述 |
| `06-02 应用岗高频问答` | 系统覆盖 65 个应用考点 | 结合项目讲，不要只背定义 |
| `06-04 真实面经高频题` | 2025–26 公开面经问法 + 趋势 | 面试前 3 天快速扫，按频次排优先级 |
| `06-05 项目深挖与追问` | 8 类项目的追问链 | 每个项目至少过 20 题，准备失败案例 |
| `06-06 手撕代码题` | 模型/Agent 特色手撕 | 手写一遍，重点记维度和边界 |
| `06-03 系统设计题` | 8 个端到端设计 | 白板练 3 个，控制 30–40 分钟 |

建议节奏：

1. **先分类**：按岗位筛掉不需要的题（如产品岗不必深挖 CUDA）。
2. **再口述**：每题 90 秒，先结论、再机制、再工程代价、最后项目数字。
3. **后手写**：公式与代码必须落到纸上，不能只在脑子里“感觉会”。
4. **最后模拟**：找同伴连续追问 5 层，训练抗压与结构化表达。

## 标注约定

- **量级/估算**：用于建立直觉，不保证精确；面试时先说明假设。
- **公开资料**：模型规格、价格、榜单等来自公开信息，可能随版本变化。
- **公式**：LaTeX 编写，可在支持 MathJax/KaTeX 的编辑器中渲染。
- **代码**：以理解原理为目标，生产环境需使用融合算子、分布式框架与成熟推理引擎。
- **来源**：题目来自公开面经，答案原创；如涉及版权问题，请联系删除。

## 内容边界

不覆盖：

- 传统机器学习/深度学习完整基础（反向传播、CNN、RNN 等），建议另行补课。
- 强化学习理论全貌（MDP、策略梯度证明），只讲大模型对齐用到的部分。
- 具体公司内部架构、数据与业务细节。
- CUDA/算子开发底层实现（只讲原理与性能直觉）。
- 最新论文逐篇解读（提供稳定框架，需自行跟进前沿）。

## 维护建议

- 每读完一篇，在“面试高频问题”旁标注掌握程度（会讲 / 会推 / 会写）。
- 遇到新模型或论文，优先更新 `07-速查` 与相关章节的“代表模型”表，而不是重写全文。
- 面试后把真实问题补进 `06-04`，把项目追问补进 `06-05`，形成个人版本。
- 通用资料的价值在框架，个人错题本才是提分关键。

> 祝面试顺利。真正的护城河不是背下多少答案，而是你能把“为什么这样设计、代价是什么、什么时候不适用”讲清楚。
